# DoNotAngry — 我们的私密空间

> 一个温馨浪漫的情侣专属网页，用心形照片墙、留言板和音乐播放器记录美好瞬间。

## 项目截图

- 主页：`home.png` 背景 + 心形区域散布拍立得风格照片 + 顶部情话文字
- 底部胶囊标签栏：照片墙 / 留言墙 / 视频 / 相册 / 小游戏
- 右侧中部：紧凑迷你音乐播放器
- 左下角 / 右下角：留言墙/视频预览卡（点击可进入）

## 开发说明

### 快速开始

直接用浏览器打开 `index.html` 即可运行（无需构建工具或服务器）。

### 配置修改

主要配置集中在 `js/config.js`：

```javascript
const CONFIG = {
  landing: { loveStartDate: '2022-03-04' },     // 计时起始日期
  heartFrame: { photoCount: { desktop: 13 } },     // 各端显示照片数
  animation: { staggerDelay: 260 },                // 飞入间隔(ms)
  decorations: { stars: { count: 5 }, hearts: { count: 4 } }, // 装饰数量
  photoRotation: { intervalSeconds: 8 }            // 照片刷新周期
};
```

### 照片管理

将照片放入 `img/she/` 目录，然后在 `js/main.js` → `loadPhotos()` 的 `imageFiles` 数组中添加文件名。
